## Overview

This repository contains a collection of hands-on Security Operations Center (SOC) investigations performed across multiple cybersecurity training platforms, including LetsDefend, CyberDefenders, TryHackMe, and Hack The Box.

The objective of this portfolio is to demonstrate practical SOC analyst skills such as alert triage, log analysis, incident investigation, and evidence-based decision making.

## Investigation Methodology

Each investigation follows a structured SOC reporting format:

                 Who – User or system involved
                 What – Suspicious activity observed
                 When – Timeline of events
                 Where – Affected systems, IPs, or domains
                 Why – Analytical reasoning and final assessment


Additional investigation components may include:

- Process tree analysis
  
- Endpoint telemetry analysis
  
- Indicators of Compromise (IOCs)
  
- MITRE ATT&CK mapping
  
- Threat intelligence enrichment
  
- Detection analysis
  
- Final verdict (Malicious / Suspicious / Benign)
